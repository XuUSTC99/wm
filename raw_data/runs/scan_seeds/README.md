# scan_seeds — three-seed completion of the 30-cell injection scan (2026-07-22)

Fills seeds 1234 and 42 for every cell of Figure 2 (the LeWM injection scan,
`fig16_scan_paper`) that was previously single-seed, so all 30 cells are now
three-seed means. 46 runs; 0 failures.

- `rollout_sc_<dom>_<arm>_s<seed>.log` — per-run rollout eval. Partition read by
  the figure: uniform/collision = both-OOD, parabola = r/m-OOD.
- `summary.tsv` — parsed nMSE per run (watchdog output).
- configs in `../../configs/sc_*.yaml` — the exact hydra config each run used.

Naming: `sc_um_*` = uniform_motion, `sc_par_*` = parabola, `sc_col_*` = collision.
Arms: structpos / reweight (pw30) / velocity (posvel pw30) / probe / probeslot /
dynmlp / ag (strict a=g = grounded, same config) / cons / labelfree.

Notes carried from the audit:
- `ag` runs feed BOTH the "[dyn] strict a=g" and "[free] grounded" heatmap rows:
  those two arms are the same configuration (fixed slot + learned-constant
  kinematic head under ground-truth labels).
- The `[cons]` arm was standardised here on the plain consistency config
  (cons=1.0, accel_weight=0, pw=1, bs=64) for all three domains; the older
  single-seed cons runs used a different variant per domain.
- uniform/structpos is NOT re-run here: its seeds 1234/42 already existed as
  `aaai_p0` runs `uniform_motion_structpos_fr_pw1_s{1234,42}` (pos_weight=1 is
  identical to the default plain-slot config).

Figure regenerated by `reports/7-11/aaai_paper/figures/fig16_scan_paper_v2.py`
via `scan_resolve.py`, which maps each cell to its per-seed logs.
