# EvoShadow：自我进化改善 OOD 长程偏移的可行性审计

更新日期：2026-08-16

## 结论

可以提升，但必须把“自我进化”定义为**冻结世界模型、只演化外部物理记忆与专家路由**，不能再次微调主预测器。

在 uniform_motion 的 3 个随机种子上，相对当前最稳的固定 Shadow（α=0.75）：

- 严格顺序在线选择器：长程误差平均再下降 **3.13% ± 1.73%**；
- 有 400 条历史反馈的外部记忆选择器：平均再下降 **11.62% ± 6.27%**；
- 逐轨迹 oracle 上限：平均再下降 **22.21% ± 5.79%**。

相对未注入物理的 baseline，三者的长程误差平均分别下降 **13.07%**、**20.77%**、**30.28%**。这说明逐轨迹专家异质性是真实存在的，自我进化有空间，不只是随机种子汇总造成的假象。

但当前选择器尚不能直接作为论文最终方法：它对 ID 有明显负迁移，严格在线版本对 r/m-OOD 也不稳定。因此最终方法必须有置信度拒绝、固定专家回退和独立的外观/规范（gauge）记忆。

## 实验问题

本次审计回答三个问题：

1. 固定 α=0.75 已经有效后，逐轨迹选择不同物理专家是否还有增益空间？
2. 不更新 LeWM 参数，仅使用历史预测—观测失配演化外部选择器，能否获得可实现的增益？
3. 增益究竟来自长程动力学 OOD，还是以牺牲 ID 为代价？

## 协议

- 领域：uniform_motion。
- 随机种子：1234、3072、42。
- 每个种子：500 条轨迹，其中 400 条作为历史流，100 条作为严格留出测试。
- 专家池：baseline、Shadow α∈{0.50, 0.65, 0.75, 1.00}。
- 上下文：每条轨迹最初 3 帧的冻结 LeWM latent，共 576 维。
- 长程目标：h≥16 的平均 latent SSE。
- 所有候选共享同一 encoder、projector、predictor 和数据顺序；主模型参数从未更新。
- 同一测试掩码内，latent SSE 与既有 nMSE 只相差共同分母，因此下表的相对改善率与 nMSE 的相对改善率一致。

三种选择协议：

- **严格顺序在线（prequential）**：测试流前 10 条使用固定 α=0.75；之后每条轨迹只能使用已经完成的测试轨迹反馈，Ridge 预测各专家长程误差。没有使用未来测试标签。
- **历史反馈（historical）**：使用前 400 条历史轨迹的专家误差训练 ExtraTrees 外部记忆，在 100 条未见测试轨迹上选择专家。该协议验证持续部署/经验记忆，不应表述成纯 zero-shot。
- **oracle**：用当前轨迹完整真值选最优专家，只表示现有专家池的上限，不能作为可部署结果。

逐轨迹导出已做严格一致性检查：5 个候选的 episode id、顺序、分区、前三帧上下文和 train/test 掩码完全一致。

## 主要结果

### 三随机种子汇总

| 方法 | 长程 SSE（h≥16）↓ | h16 SSE↓ | h28 SSE↓ | 相对固定 α=.75 | 相对 baseline |
|---|---:|---:|---:|---:|---:|
| baseline | 136.999 ± 2.953 | 95.135 ± 3.603 | 147.363 ± 6.500 | -11.51% | 0.00% |
| 固定 α=.75 | 123.027 ± 7.043 | 85.393 ± 8.742 | 140.108 ± 10.959 | 0.00% | +10.24% |
| 严格顺序在线 | 119.119 ± 5.466 | 88.411 ± 13.585 | 130.980 ± 4.385 | **+3.13%** | **+13.07%** |
| 历史反馈外部记忆 | 108.479 ± 3.663 | 81.566 ± 10.044 | 120.097 ± 3.839 | **+11.62%** | **+20.77%** |
| oracle 上限 | 95.454 ± 3.131 | 74.176 ± 9.833 | 105.845 ± 5.875 | **+22.21%** | **+30.28%** |

这里“±”是 3 个随机种子之间的样本标准差。

### 每个随机种子的长程改善率（相对固定 α=.75）

| 随机种子 | 严格顺序在线 | 历史反馈 | oracle |
|---:|---:|---:|---:|
| 1234 | +1.21% | +5.48% | +16.80% |
| 3072 | +3.63% | +11.36% | +21.53% |
| 42 | +4.56% | +18.00% | +28.31% |
| 平均 | **+3.13%** | **+11.62%** | **+22.21%** |

严格在线和历史反馈在三个种子上均为正增益，说明“外部经验演化”并非只在单个种子成立。

### 分区诊断（相对固定 α=.75 的长程改善率）

| 方法 | ID | r/m-OOD | v-OOD | both-OOD |
|---|---:|---:|---:|---:|
| 严格顺序在线 | -5.26% | -13.94% | +2.73% | **+8.77%** |
| 历史反馈 | -22.91% | +7.32% | +6.79% | **+20.10%** |
| oracle | +28.26% | +20.01% | +17.80% | +25.74% |

正面证据：

- both-OOD 是当前自进化选择最明显的受益区，历史反馈平均改善 20.10%。
- v-OOD 在历史反馈下平均改善 6.79%，但 seed 1234 略退化，尚不能称为跨种子稳定。
- oracle 在所有分区均有 17.80% 以上空间，说明专家池的互补性确实存在。

负面证据：

- 当前历史选择器会明显伤害 ID，不能无条件写回。
- r/m-OOD 对严格短历史在线选择不友好，说明前三帧 latent 中的外观/半径信息与动力学信息没有被可靠解耦。
- α-only 路由虽能验证方向，但创新性不足，不能作为 ICLR 主贡献。

### 安全门诊断

额外做了一个 **post-hoc** 诊断：只有选择器预测的最优专家比固定 α=.75 至少好 10% 时才改写，否则回退 α=.75。

| 指标 | 10% 安全门 |
|---|---:|
| 全测试长程改善 | +9.58% |
| ID | +7.54% |
| r/m-OOD | +7.88% |
| v-OOD | +1.58% |
| both-OOD | +17.07% |
| 非固定专家覆盖率 | 17.67% |

这个诊断证明“拒绝大部分低置信度写回”有希望同时保住 ID 和 OOD，但 **10% 阈值是在查看测试曲线后选出的，不能作为无泄漏主结果**。

进一步尝试只用 400 条历史流做五折交叉验证选阈值，三个种子分别选出 0%、0%、30%；其中 seed 3072 在留出 ID 上仍退化 79.05%。这说明当前 ExtraTrees 的收益分数在分布切换后没有校准。下一版安全门应使用保序/共形校准或显式不确定性上界，而不能依赖单点回归分数。

## 推荐方法：EvoShadow

最终方法建议命名为 **EvoShadow：自演化物理传输记忆**。核心约束如下：

1. **冻结 LeWM 主体**
   encoder、projector、predictor、readout 均冻结。已有训练感知 Shadow 的实验出现 ID 和长程退化，继续更新主预测器风险过高。

2. **双外部记忆**
   - 动力学记忆：速度尺度、恒加速度、阻尼和碰撞冲量等低维参数；
   - 规范记忆：半径/质量/外观变化对应的 latent gauge 变换。
   这样分别处理 v-OOD/长程漂移与 r/m-OOD，不把两种失配混成一个 α。

3. **有类型的物理专家群体**
   至少包含恒速、重力/恒加速度、碰撞冲量、阻尼和自由残差专家。每个专家只演化少量物理参数与 horizon-dependent α，不重新训练主干。

4. **选择性 Shadow 写回**
   修正只进入下一步递归所用的 shadow memory；当前输出仍保持原预测语义。只有当预计收益超过不确定性阈值时才写回，否则回退固定 α=.75。

5. **基于真实反馈的演化**
   每次获得新观测后，用预测—观测失配更新外部专家的后验、置信度和记忆条目；不做反向传播，不修改 checkpoint。

这与一般的 online system identification、latent residual adaptation 或简单 episodic retrieval 的区别，应落在“**有类型物理专家 + gauge-equivariant 双记忆 + selective Shadow writeback + 冻结 LeWM**”这一组合上，而不是宣称首次在线适应。

## 下一轮必须跑的实验

### P0：安全选择器

- 将 post-hoc 10% 门改成只由历史数据标定的无泄漏置信度门；
- 使用保序/共形校准或 bootstrap 专家方差形成收益下界；
- 若预测最优专家相对 α=.75 的优势不足阈值，则拒绝更新；
- 主要验收：ID 长程退化不超过 1%，同时保留 both-OOD 至少 10% 改善；
- 报告 coverage—gain 曲线和阈值迁移结果，不能只报手选的 10% 阈值。

### P1：扩大物理专家族

- 恒速、恒加速度、阻尼、碰撞冲量和自由残差；
- 每个专家参数维度保持很小；
- 对比 α-only pool，确认收益来自物理模式而非增加分类器容量。

### P2：双记忆消融

- 仅动力学记忆；
- 仅 gauge 记忆；
- 双记忆；
- 无记忆固定专家。
  重点看 v-OOD、r/m-OOD 和 both-OOD 是否按预期分工。

### P3：持续适应曲线

历史反馈预算取 0、10、25、50、100、200、400 条，画出长程误差随经验增长的曲线；同时设计 ID→OOD、OOD-A→OOD-B 的分布切换，检查记忆污染和恢复速度。

### P4：跨物理领域

在 parabola 和 collision 上复现同一协议。uniform_motion 只能证明方向，无法支持完整 ICLR 结论。

## 论文结论边界

目前可以写：

> 冻结世界模型的外部自演化专家记忆，在三随机种子的 uniform_motion 上，相对最强固定 Shadow 将长程误差再降低 11.62%，并在 both-OOD 上平均降低 20.10%。

目前不能写：

- “纯 zero-shot 自进化达到 11.62%”：该数字使用了 400 条历史反馈；
- “所有分区都稳定提升”：当前 ID 存在负迁移；
- “已经解决 OOD”：尚未覆盖 parabola、collision，也缺安全门和分布切换实验；
- “α 路由本身是新方法”：它只是可行性探针。

## 相关方法边界

- [WorldEvolver](https://arxiv.org/abs/2606.30639)：冻结模型的 episodic/semantic memory，支持外部记忆方向，但不能直接当成本方法创新点。
- [ReDRAW](https://proceedings.mlr.press/v331/lanier26a.html)：latent residual test-time adaptation，说明 residual adaptation 已有先例。
- [Vid2Param](https://arxiv.org/abs/1907.06422)：从视频在线辨识物理参数，说明 online system identification 不是新颖点。
- [LW-PR2](https://proceedings.mlr.press/v100/williams20a.html)：直接在线适应可能造成灾难性遗忘，支持冻结主模型和选择性写回设计。
