# ICLR 方法新颖性与设计约束

更新时间：2026-08-05

## 1. AAAI 失败证据给出的硬约束

AAAI 阶段已经排除了把物理信息“再塞进共享 latent”的主流路线。未注入物理的 LeWM 表示中，真实帧位置本来就能被线性读出；真正退化的是预测 latent 在闭环 rollout 中的状态演化。因此，新方法必须修正“演化误差”，不能再优化“状态是否可读”。

已有负结果覆盖：

- 固定物理 slot、probe 深监督、位置/速度扩展 slot；
- 自由或固定形式的二阶动力学头；
- 状态与速度 consistency loss；
- 有标签和无标签的平滑物理先验；
- 单纯提高物理损失权重；
- 单纯 free-rollout（它是必要强基线，但不是创新点）。

这些方法失败的共同机制是：重复注入已有状态、物理项与预测项争梯度、共享表示有效维度塌缩，或在接触事件上使用错误的光滑动力学。

## 2. 查新后的直接结论

“每一步把预测投影回物理约束流形”不能单独作为创新点。相近类别至少包括：

- 约束动力系统中的 hard/manifold projection；
- Projected Neural ODE 与 semi-explicit Neural DAE；
- neural projection operators；
- 潜空间中的物理 consistency、物理/残差分解；
- 视觉 world model 的离散最小作用量/变分积分器；
- 推理期物理 guidance 或候选轨迹搜索。

因此，当前 GIPP 的固定强度线性投影只作为诊断基线。若它有效，论文也不能声称“首次做 latent physics projection”。

## 3. 暂定 ICLR 方法：因果承重、自校准的混合物理校正

暂名：**Causal Gauge-Equivariant Residual Transport（C-GERT）**。

核心不是创建新的物理 slot，而是复用黑盒 latent 中已经存在的物理状态，并只在闭环漂移时运输最小必要残差。

### 3.1 冻结读出，不改表示

在真实帧 latent 上拟合冻结状态读出器及其不确定度，不通过物理损失更新 encoder。这样直接避开 AAAI 已证实的梯度冲突和表示塌缩。

### 3.2 因果承重方向，而非“可解码方向”

线性 probe 的相关方向不等于 predictor 真正依赖的方向。用 latent intervention / Jacobian response 测出：改变某个状态分量时，哪些 latent 切向方向真正改变后续 rollout。校正只沿这些因果承重方向回写，避免对不可见但可读的冗余副本做无效投影。

这是相对普通最小距离 projection 的第一项关键区别。

### 3.3 坐标重参数化等变

校正由 latent 协方差度量和读出 Jacobian 联合定义，使任意可逆线性 latent 换基后，解码状态轨迹保持一致。实验必须加入随机正交变换和非均匀缩放换基测试；欧氏投影应退化，而本方法输出应保持一致。

这解决视觉 latent 没有天然坐标系的问题，也是方法可陈述的理论性质。

### 3.4 创新量门控，而非固定 α

根据三类不确定度逐步决定校正强度：

1. 读出器在当前 latent 是否处于训练支持域；
2. 黑盒预测与候选物理模型的 innovation 是否显著；
3. 物理模型自身对当前事件是否可信。

ID 且黑盒正确时门控接近零；长程漂移或动力学 OOD 时才增强。固定 α 的 GIPP 是其消融，不是最终方法。

### 3.5 混合动力学与接触事件

统一的光滑加速度先验不能处理 collision。候选模式至少包括匀速、恒重力、自由残差和碰撞冲量；由历史 innovation 与碰撞证据选择或软混合。物理不确定时保留黑盒残差，而不是强行投影到错误方程。

## 4. 必须过的 ICLR 证据门槛

方法只有同时满足以下条件才保留：

- 相对 LeWM + free-rollout + 最优增广，在长程和 OOD 主指标上稳定提升；
- 三个或以上随机种子，报告均值、标准差和配对显著性；
- horizon 1–28/更长完整曲线，而不是只挑终点；
- ID 不显著下降，尤其不能用物理一致性换视觉预测质量；
- 与 fixed-slot、probe、consistency、普通欧氏投影、固定 α 投影、PIWM/变分方法做公平对照；
- 消融分别证明因果方向、换基等变、置信门控、混合动力学的贡献；
- collision 接触前、接触瞬间、接触后分段报告；
- PhyWorld 之外至少一个真实视频/物理数据集验证迁移。

## 5. 当前实验定位

正在运行的 action-free 基线与三档 GIPP 用于回答两个问题：

1. 不改 encoder 的 rollout 校正能否避开旧方法的表示塌缩；
2. 固定投影在何种域、何种 horizon 开始有益或有害。

若固定投影无稳定提升，将根据误差分段直接转入因果方向与自校准门控，而不是继续堆权重。若它有提升，也只作为 C-GERT 的基础消融，不作为最终新颖性主张。
