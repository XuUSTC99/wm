A world model predicts how an environment evolves in response to actions by rolling an internal representation forward, and is expected to respect physical regularities such as how objects move and collide.
We study JEPA-style latent world models and find a puzzle: trained with no physics supervision, such a model already recovers object position well from its representation, predicts one step almost exactly, and---as counterfactual intervention confirms---actually uses that state when rolling forward, yet its multi-step rollouts still drift away from the very dynamics it encodes.
The popular fix is to inject physical structure into the latent representation.
We test it systematically within the family it names---ten variants that write physics onto the coordinates of the shared latent, spanning hard and soft constraints on both physical quantities and physical laws, with labeled and label-free supervision---across three controlled physics domains and two realistic simulation benchmarks, and find injection fails in $29$ of $30$ cases; even supplying the \emph{correct} physical constraint does not help.
One account fits every test we ran: the physical state is already encoded, redundantly, across a \emph{shared latent}, so an injected copy carries no new signal while the constraint still competes for capacity and gradient. Intervening on a trained model shows the injected slot is \emph{load-bearing but redundant}: perturbing it moves the model's own black-box state $1.5$--$2.0\times$, and swapping it for another trajectory's makes prediction follow that trajectory $47$--$72\%$ of the way---yet the black box keeps its own copy, and prediction error does not move. Both routes carry load; the second carries nothing new.
What the model lacks is not the object's physical state but the ability to evolve that state over long horizons: fixing the training procedure alone, adding no physics, cuts rollout error $2.2$--$8.3\times$ on identical code and metrics. To help a latent world model, injected structure should supply what the representation is missing---\emph{how the state evolves, not what the state is}.
