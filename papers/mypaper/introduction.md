# Introduction（中文第一版草稿）

> 主线：**当前视频世界模型仍然缺乏对物理规律的可靠遵循**。它们可以从视觉输入中编码物体的位置、大小等状态信息，但在多步滚动预测时容易偏离真实动力学。本文的核心做法是在世界模型训练损失中加入显式的位置物理量监督，使 latent 表征更对齐真实物理状态，从而提升模型对运动规律的遵循能力和对世界状态的理解。

## 1. 引言

视频世界模型近年被视为通向通用智能体的重要组件：如果模型不仅能复现像素外观，还能预测物体如何运动、碰撞和下落，那么它就可能为规划、控制和交互提供一个可泛化的内部世界。然而，现有世界模型距离这一目标仍有明显差距。它们往往能在短时间内生成合理的下一帧，却会在多步滚动中逐渐漂移；能在隐空间中保留部分物体状态，却不一定能稳定遵循背后的物理规律。换言之，**可解码的状态表征并不等价于真正可靠的物理理解**。

这一问题在物理外推场景中尤其突出。对于匀速运动、抛体运动和碰撞等简单系统，一个真正理解物理规律的世界模型应当能够在未见过的速度、半径或组合条件下保持一致的动力学预测。但我们观察到，预训练世界模型虽然已经在 latent 中编码了丰富的视觉和位置线索，滚动预测仍会随 horizon 增大而累积误差，在 OOD 条件下更容易偏离真实轨迹。这说明当前 WM 的瓶颈并不只是“有没有看见物体”，而是**是否把物体状态组织成一个有利于物理演化的表示**。

为此，本文研究一个简单但直接的假设：如果世界模型的 latent 表征能够被显式约束去对齐关键物理量，尤其是物体位置，那么模型在预测未来状态时应当更容易遵循物理规律。我们在原有的 latent prediction loss 之外加入一项位置物理量监督，即通过轻量 probe 从 latent 中读出真实位置，并将该误差作为训练信号反馈给 encoder / predictor。这个目标并不是让模型记住某个任务的解析方程，而是让它在学习视觉预测的同时，将内部状态组织到更可解释、更可演化的物理坐标上。

我们的实验表明，位置物理量监督能够改善世界模型对状态信息的保持和利用。以 PhyWorld 的匀速运动为例，仅凭 192 维 CLS embedding 训练出的像素 decoder 已经可以高质量重建球的位置和大小，说明预训练 latent 中确实包含状态信息；进一步在微调阶段加入位置监督后，通用 decoder 在 ID 与 OOD 分区上的重建质量均得到提升，且没有出现“牺牲 OOD 信息换取 ID 拟合”的现象。这表明显式物理监督并不是简单地把 OOD 状态拉回训练分布，而是在增强 latent 中与真实物理状态相关的可读性。

更重要的是，我们进一步区分了“静态可解码性”和“动态预测能力”。单纯的 probe 相关性或 decoder PSNR 容易受到指标循环的影响：如果训练目标本身就鼓励位置可解码，那么相应读出指标自然会上升。因此，本文采用更严格的像素级 rollout 评估：先让 world model 在 latent 空间中自回归预测未来，再将预测 latent 解码为像素帧，与真实未来帧比较。该评估直接衡量模型滚动后的物理预测质量。结果显示，加入位置物理量监督不会破坏 world model 的多步预测，合适的监督强度还可以带来更稳定的预测表现。

同时，我们发现物理监督的形式必须与任务动力学匹配。多帧速度监督并不是普适最优：在匀速运动中，单帧位置监督已经足以提供干净的状态约束；而在抛体运动中，速度随重力变化，多帧窗口能提供额外动力学信息；在碰撞场景中，速度变化集中在稀疏事件附近，监督粒度的效果随分区而变。这说明，有效的物理监督不应被理解为“把所有物理量都加进 loss”，而应根据系统中哪些状态量真正影响未来演化来设计。

本文的贡献如下：

- **指出当前世界模型的关键不足**：预训练 WM 可以编码物体状态，但多步滚动中仍难以稳定遵循物理规律，尤其在 OOD 物理条件下会出现累积漂移。
- **提出一种简单的物理量深度监督方法**：在原有 latent prediction loss 之外加入位置物理量监督，使 latent 表征更对齐真实物理状态，从而帮助模型学习更可演化的世界状态表示。
- **通过像素级 rollout 验证物理监督的实际作用**：区别于只看 probe 相关性或静态 decoder PSNR，我们评估预测 latent 解码后的未来帧质量，验证位置监督不会损害 world model，并能在合适强度下改善物理预测稳定性。
- **揭示监督粒度依赖物理结构**：单帧位置监督、多帧位置/速度监督的效果取决于被监督物理量在轨迹内是否变化；这为后续设计面向物理世界模型的 loss 提供了经验准则。
